# P7-01 the public HTTP contract

## Generated, not written

`contracts/public/openapi.json` is derived from `contracts/security/actions.json` — the
one place that already says which actions exist, who may call them, and which surfaces
they cover.

That is the whole point. A hand-written public API drifts: an operation appears that no
action covers and is therefore unauthorizable, or an action is added and the contract
silently does not mention it. Deriving the contract makes both impossible, and the gate
checks it on every run.

- **76 published operations**, one per registered signed shell action.
- **1 withheld**: `/creatures/login`, whose policy rule is `never` (RL-019, ADR 0019).
  Publishing an operation that can only ever be denied would be a trap for a client
  author.

## What the contract fixes

| Concern | How |
|---|---|
| Authentication | `Aseman-Session` for a user session, `Aseman-Proof` for an A401 signed request. A session identifier is a bearer credential and is never mapped or logged |
| Idempotency | `Idempotency-Key` is **required for every action that is not a read**. Issuing a session, rotating a key, moving money — a retry of any of those must not repeat the effect |
| Errors | RFC 9457 problems, with `aseman_reason` carrying the stable refusal reason a client branches on |
| Tracing | `Aseman-Request-Id`, echoed in the response |
| Authorization | Each operation carries `x-aseman-action`, so a reader can see which policy decision governs it |

## One API, several transports

The legacy TCP and WebSocket transports carry these same actions. They are framing
adapters over this contract, not a second API with its own semantics — which is what
P7-05 finishes, and what keeps "one session and application path" true.

## Verification

`python3 scripts/generate_public_api.py --check` runs in `cargo xtask fast`. It fails
when the published contract and the registry disagree — verified by tampering: deleting
one operation from the checked-in document makes the check fail, and restoring it makes
it pass.

The registry generator already fails when an inventoried surface maps to no action, so
the two checks together mean: every surface is authorizable, and every authorizable
surface is published or explicitly withheld.

## Open, and owned

- **Serving it.** The hardened HTTP stack, its middleware (rate, concurrency, body and
  duration limits, CORS, draining), and the SSE and WebSocket streams are the node's
  shell to implement against this contract.
- **Generated SDKs** and the compatibility policy follow the contract's `info.version`;
  a breaking change is a new version, never an edit in place.
- **A702 gateway RPC** and **A703 listener broker** are the module-facing side of the
  same transport work.
